### **Resumen**

Novartis aprobó la infraestructura y el cronograma para lanzar un sitio web educativo sobre urticaria crónica.

**Aprobación de infraestructura técnica**  
Novartis autorizó la infraestructura y el uso del dominio para el proyecto. Se decidió implementar un sistema propio de desarrollo para gestionar el frontend y la analítica.

**Estrategia de contenidos SEO**  
Se planeó la creación de 7 contenidos iniciales y la integración de una herramienta de autodiagnóstico. Todo el material requiere validación médica para garantizar precisión y neutralidad.

**Cronograma y lanzamiento**  
El sitio web se lanzará el 11 de octubre para coincidir con el Día Mundial de la Urticaria. Se estableció un mantenimiento bimensual para actualizaciones y auditorías SEO.

### **Decisiones**

## Acordada

* **Volumen de contenidos iniciales fijado** Se acordó que el lanzamiento del sitio incluirá exactamente siete piezas de contenido inicial, permitiendo flexibilidad en su distribución entre blogs y otros medios.

* **Frecuencia de mantenimiento técnico SEO** Se estableció que el mantenimiento técnico SEO se realizará de forma bimensual, excluyendo el mes de agosto.

* **Sistema de gestión de contenidos definido** Se determinó que el sitio web y el blog se construirán utilizando el sistema 'kosco' en lugar de WordPress.

* **Alcance del proyecto limitado a diciembre** El alcance del proyecto se definió hasta el mes de diciembre, condicionado por los presupuestos anuales.

* **Variables de personalización del sitio definidas** Se acordó utilizar el clima, la geolocalización y la hora del día como las variables principales para la personalización dinámica del sitio web.

* **Nombre de herramienta definido como quiz** Se decidió que la funcionalidad interactiva del sitio se denominará 'quiz' y no 'autodiagnóstico'.

* **Plazos de entrega del proyecto fijados** Se establecieron los plazos de entrega: el cuestionario para el 11 de septiembre, el contenido y textos para el 15 de septiembre, y la estructura técnica para el 16 de septiembre.
